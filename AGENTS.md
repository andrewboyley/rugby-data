# Rugby Data

This package builds a cached, versioned dataset of international rugby union
matches. It downloads data from World Rugby RIMS and ESPN. It is a data pipeline.
It does not predict results.

## Stack

- The Python package is in `src/rugby_data/`. It needs Python 3.12 or later.
- The generated `data/dataset.json` file is a versioned consumer artifact.
- The API cache and the generated data stay local. The repository ignores them.
- The tooling is modern: FastAPI and Uvicorn for the API, HTTPX and Tenacity
  for transport, Typer for the command-line interface, and Pydantic v2 for the
  data models.

## Commands

```sh
just setup          # install dependencies
just dataset        # build dataset
just check          # type check
just test           # run tests
just lint           # lint and format check
just install-hooks  # install pre-commit hooks (once per clone)
just hooks          # run all hooks manually
```

## Data contract

`Dataset.save()` writes `schemaVersion: 1`, `generatedAt`, the games, and the
entity registries. Event, player, coach, venue, and league IDs stay source
strings. Team IDs are numbers. The build keeps only complete games.

The optional API must serve this contract. It must not make a second graph
export. The API is read-only. It must not expose the API cache and must not
download from the sources.

## Rules

- Do not edit the generated data under `data/` by hand.
- Keep the incremental saves, the processed markers, and the cache behavior.
- Never commit API responses, generated data, credentials, or local state.
- Do not commit, amend, or push unless the user asks.
